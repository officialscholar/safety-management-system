# 综合安全管理系统

一个**纯前端、单文件、免安装**的建筑项目施工安全管理工具。整个系统就是根目录下的 `综合安全管理系统.html`，用浏览器（推荐 Edge / Chrome）直接打开即可使用，数据保存在浏览器本地，并可自动归档到软件所在目录的实体文件夹中。

---

## 1. 项目解决什么问题

施工现场安全管理日常存在以下痛点：

- **资料散、易丢失**：安全日志、隐患台账、整改通知、专项方案、管理制度等分散在 Word/Excel 和聊天记录里，换电脑、重装系统后资料难找难管；
- **台账手工维护费时**：隐患台账、风险辨识、危大工程清单靠 Excel 手工排版，统计口径不统一；
- **文书格式不规范**：整改通知书、处罚单等对外文书每次重新排版，格式忽东忽西；
- **文件没有统一归档位置**：方案、照片、处罚单正本散落各处，检查前临时翻找。

本系统把以上安全管理业务整合到一个页面里：**在线填写 → 自动统计 → 一键导出标准格式 Word/Excel → 原件自动归档到本地文件夹**，无需服务器、无需数据库、无需联网登录，换电脑时用「一键打包」即可整体迁移。

---

## 2. 主要功能

系统顶部导航包含以下模块（首页均有数据统计卡片直达）：

| 模块 | 功能说明 |
| --- | --- |
| **首页** | 各模块数据总览；「一键打包」把全部模块数据 + 制度附件原件打包为 zip，换电脑/换浏览器可一键还原 |
| **基础数据** | 项目信息、单体建筑、项目人员、劳务班组维护；可导出项目通讯录（Excel）、人员信息表 / 班组信息表（Word） |
| **安全日志** | 按日期编写安全日志（当日施工内容与风险、检查情况、限期整改隐患一览表等），可自动生成并导出 |
| **隐患台账** | 隐患录入、批量删除；支持下载 Excel 模板导入，或直接从 Excel/WPS 复制多行粘贴导入，自动去重 |
| **隐患治理** | 按记录日期管理隐患治理记录，支持 Ctrl+V 粘贴现场照片；可导出《施工（生产）现场隐患整改通知书》《整改回复》Word 文件（版式对照上传模板） |
| **风险识别** | 风险辨识清单管理，一键导出风险台账（Excel） |
| **危大工程** | 危大工程清单管理，一键导出危大工程台账（Excel） |
| **操作规程** | 按工种维护安全操作规程，可导出《安全操作规程交底表》Word（A4、宋体、7 列网格版式） |
| **管理制度** | 安全管理制度的录入、编辑、版本迭代，附件原件自动归档；可导出汇编 Word |
| **专项方案** | 安全专项方案上传归档，固定四类分类：危大工程专项方案、项目通用必备安全专项方案、专项作业/设备类方案、应急类方案；**不限文件大小**，支持 Word/Excel/PPT/PDF/图片/压缩包等常见格式在线预览，同名文件自动加序号不覆盖 |
| **违约处罚** | 开具安全违约处罚单：填写责任单位、金额、罚款事由（每行一条自动编号）、现场照片等，**以用户上传的 Word 模板为底板导出**——模板原有字体、字号、表格、合并单元格、页眉页脚、页面设置全部保留，仅替换填写内容；支持上传公司 Logo、设置模板信息 |
| **文件库（本地资料库）** | 授权软件目录下的「安全资料库」文件夹后，所有上传的方案、制度附件、处罚单正本、现场照片自动按模块/类型分文件夹写入磁盘，可直接在资源管理器查看、备份；未授权时自动回退浏览器存储，不影响使用；支持旧文件一键同步归档 |

**数据存储与迁移**

- 结构化数据保存在浏览器 localStorage，照片等大文件保存在 IndexedDB；
- 连接本地文件库后，原件实体自动写入 `安全资料库/` 对应分类目录（如 `安全资料库/安全专项方案/危大工程专项方案/`、`安全资料库/安全违约处罚单/处罚单正本/`）；
- 「一键打包」生成的 zip 可在任何电脑上还原全部数据与附件。

## 3. 安装方法

本系统无需编译、无需安装依赖：

1. 将整个项目文件夹（含 `综合安全管理系统.html`）拷贝到目标电脑任意位置（建议放一个固定目录，方便文件库归档）；
2. 双击 `综合安全管理系统.html`，或右键 → 打开方式 → 选择 Edge / Chrome；
3. 首次使用建议点击顶部「文件库」按钮，选择软件所在目录（授权后系统会在其下自动创建「安全资料库」文件夹用于归档上传原件）。

> 说明：所有功能在离线状态可用；浏览器弹出新窗口（用于打印/导出）需允许弹窗。

## 4. 使用方法

典型日常使用流程：

1. **一次性初始化**：首页 →「基础数据」录入项目信息、单体、人员、班组；「管理制度」「操作规程」录入或导入现有制度文件；
2. **连接文件库**：点击顶部「文件库」→ 选择软件所在目录 → 完成浏览器目录授权；
3. **日常记录**：
   - 「安全日志」按日期填写当天检查情况；
   - 「隐患台账」录入隐患，或用 Excel 模板批量导入；
   - 「隐患治理」登记整改情况、粘贴现场照片，导出整改通知书/整改回复单发给分包单位；
   - 「违约处罚」→「开具处罚单」填写内容并生成，列表中可预览、导出 Word、删除；
4. **资料归档**：「专项方案」上传方案原件，自动按四类归档并写入本地文件夹；
5. **统计导出**：风险、危大工程台账一键导出 Excel；通讯录、人员/班组信息表一键导出；
6. **备份迁移**：首页 →「一键打包」下载 zip；换电脑后在新电脑打开系统 → 一键还原即可恢复全部数据与附件。

## 5. 输入输出示例

### 示例一：开具违约处罚单

**输入**（「开具处罚单」表单）：

- 处罚单号：自动生成，如 `WY-AQ-20261029-001`
- 责任单位：XX劳务-木工班组
- 罚款事由（每行一条）：

  ```text
  未按要求佩戴安全帽
  高处作业未系挂安全带
  ```

- 罚款金额：500 元；现场照片若干张；签收人员：张三

**输出**：

- 系统内生成一条处罚单记录（列表显示单位、单号、金额、照片数，首页统计「本月开具 / 累计罚款」）；
- 点击「导出 Word」得到 `安全违约处罚单_XX劳务-木工班组_20261029.docx`——以上传的公司模板为底板，事由自动编号为 ①②，字体、表格、页边距与模板完全一致；
- 处罚单正本自动归档至 `安全资料库/安全违约处罚单/处罚单正本/`，现场照片归档至 `安全资料库/安全违约处罚单/现场照片/`。

### 示例二：隐患整改闭环

**输入**：隐患台账导入（Excel 模板列：隐患部位、隐患内容、整改责任人、期限等），或从 Excel 复制多行粘贴导入。

**输出**：隐患台账自动生成；进入「隐患治理」添加整改记录、Ctrl+V 粘贴整改前后照片，一键导出《施工（生产）现场隐患整改通知书》和《整改回复》Word 文件。

### 示例三：数据备份与迁移

**输入**：首页点击「一键打包」。

**输出**：得到一个 zip 包，内含全部模块数据（安全日志、隐患台账、治理记录、风险、危大工程、规程、制度、方案、处罚单等）与制度附件原件；在新电脑上打开系统并「一键还原」，各模块数据与附件完整恢复。
